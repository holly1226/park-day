# 公园的一天

目标用户：公共空间与交互设计师、社区运营者，以及想探索公园使用情况的居民。

核心路径：切换天气、拖动时间轴 → 在地图查看人流与占用 → 点设施看详情 → 通过 AVA 查询寻找空间使用差异 → 查看 SQL、结果数据与口径。

本轮范围：一座原创像素公园、两种天气、06:00–21:00 半小时时段、设施占用/人流/树荫图层、五类预设查询、可下载的模拟数据与分析结果、可选本地模型自由问答、GitHub Pages 静态演示。

不做：真实传感器接入、识别个人、真实天气预测、自动设计优化、把模拟结果写成实测结论。

数据：确定性生成的模拟观测，单位为一个设施在一个半小时时段的观测。到访人次允许跨设施重复；占用人数为该时段抽样快照；座椅容量与其他设施容量分别标注；停留时间为该设施该时段模拟平均值。遮阴是示意图层，非真实日照计算。

AVA：浏览器端 @antv/ava 4.0.4 + 社区 ava-engine-duckdb-wasm 0.1.1。数据 source → schema/semantic → query 均真实执行。无密钥使用预定义参数化 SQL；自由问题需本地服务配置模型后走 AVA analyze。自绘地图与图表由 AVA 查询结果驱动，不宣称由 AVA 生成。

验收：无密钥可运行；天气、时间、图层、设施详情与分析联动；所有查询可查看 SQL/数据；加载/失败/空结果有反馈；移动端可用；密钥不进入客户端或仓库；构建、数据不变量和真实浏览器 AVA 查询通过。
